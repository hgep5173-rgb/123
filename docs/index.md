# Lua API Документация

Добро пожаловать в документацию Lua API! Данный ресурс предназначен для помощи в написании скриптов, предоставляя исчерпывающее описание всех доступных типов данных, глобальных функций и методов, экспортированных из C++ движка.

## Структура документации

В вашем распоряжении следующие разделы:

* [**Типы данных (Types)**](types.md) — Описание базовых и игровых типов, таких как вектора (`vec3\_t`), углы (`angle\_t`), цвета (`color\_t`), а также игровые события (`game\_event\_t`) и параметры камеры (`view\_setup\_t`).
* [**Глобальные таблицы (Engine)**](engine.md) — Математические функции, конвертация углов и векторов, работа с переменными меню (`menu`).
* [**Сущности (Entity)**](entity.md) — Полное руководство по работе с игровыми сущностями (`base\_entity\_t`), чтение и запись сетевых переменных (netvars), а также получение информации об игроках.
* [**Рендер (Render)**](render.md) — Инструменты для загрузки шрифтов и работы с текстурами (включая динамические RGBA текстуры).
