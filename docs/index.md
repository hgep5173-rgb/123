# 🏠 Добро пожаловать в CS2 Lua API

Официальная документация для разработчиков скриптов. Наш Lua-движок построен на современных C++ стандартах с использованием библиотеки `sol2` для обеспечения максимальной производительности, гибкости и безопасности (с флагом `SOL_ALL_SAFETIES_ON`)[cite: 14].

---

## ⚡ Особенности движка

* **Продвинутый Рендеринг**: Нативная интеграция с ImGui, поддержка загрузки кастомных шрифтов, панорамных `.vsvg` и динамических RGBA текстур с обработкой `flip_y`[cite: 14].
* **Безопасность**: Автоматическая система изоляции. При возникновении критических ошибок (Runtime Error) проблемный скрипт безопасно выгружается, не вызывая краша игры[cite: 14].
* **Прямой доступ к памяти**: Оптимизированный Pattern Scanner и Hook Manager для работы напрямую с классами движка CS2[cite: 14].

---

## 🔌 Система Коллбеков (Callbacks)

Скрипты взаимодействуют с игрой посредством регистрации обратных вызовов (коллбеков). Движок позволяет подписываться на ключевые события:

| Событие | Описание | Класс в памяти |
| :--- | :--- | :--- |
| `"paint"` | Вызывается каждый кадр при отрисовке на экране. Идеально для ESP и кастомных UI. | `-`[cite: 14] |
| `"game_event"` | Обрабатывает внутриигровые серверные события (убийства, взрывы бомбы, урон). | `CGameEvent`[cite: 14] |
| `"override_view"` | Позволяет переопределять FOV, позицию камеры и перспективу локального игрока. | `CViewSetup`[cite: 14] |

!!! example "Базовый шаблон скрипта"
    ```lua
    -- Обработка отрисовки
    register_callback("paint", function()
        render.text("Hello CS2!", 1, vec2_t(15, 15), color_t(255, 255, 255, 255))
    end)

    -- Обработка событий игры
    register_callback("game_event", function(event)
        if event:get_name() == "player_death" then
            print("Кто-то умер!")
        end
    end)
    ```

## 📂 Управление скриптами

Все загружаемые файлы отслеживаются системой. Скрипт имеет поля `filename`, `full_path`, а также флаги `enabled` и `is_loaded`, что гарантирует корректную работу менеджера скриптов при их перезагрузке или ошибках[cite: 14].
