# 📖 CS2 Lua API Documentation

Добро пожаловать в официальную документацию Lua API. Наш движок основан на **Sol3** и **LuaJIT**, поддерживает FFI, прямую работу с памятью игры, мощный рендер на базе ImGui и безопасное взаимодействие с движком CS2.

---

## 🌍 Глобальные функции (Globals)

Базовые функции, доступные в любом месте скрипта без дополнительных таблиц.

### `print(...)`
Выводит текст в консоль игры белым цветом. Поддерживает любое количество аргументов.
```lua
print("Loaded!", "Version:", 1.5)

color_print(text, [color])

Выводит цветной текст в консоль игры. Идеально для красивых логов.

  - text string — Текст для вывода.
  - color color_t (опционально) — Цвет текста (по умолчанию белый).

color_print("[Cheat] Script loaded successfully!", color_t(50, 255, 50))

get_game_directory()

Возвращает абсолютный путь к папке с игрой (до game\bin\win64).

  - Возвращает: string

find_pattern(module_name, pattern, [offset])

Ищет паттерн (сигнатуру) в памяти указанного модуля.

  - Возвращает: lightuserdata (указатель). Совместимо с ffi.cast.

local ptr = find_pattern("client.dll", "48 8B 0D ? ? ? ? 48 89 7C 24", 0)

find_export(module_name, export_name)

Ищет экспортируемую функцию в указанном модуле.

  - Возвращает: lightuserdata (указатель).

get_user_name()

Возвращает имя текущего пользователя Windows.

  - Возвращает: string

🔄 События (Callbacks)

register_callback(event, callback)

Регистрирует функцию для вызова по определенному событию игры или чита.

| Событие           | Описание                                                        | Аргументы коллбека |
| :---------------- | :-------------------------------------------------------------- | :----------------- |
| `"paint"`         | Вызывается каждый кадр. Здесь должны быть все функции `render`. | \-                 |
| `"override_view"` | Вызывается для изменения параметров камеры.                     | `view_setup_t`     |
| `"game_event"`    | Вызывается при любом событии движка CS2.                        | `game_event_t`     |
| *Имя ивента*      | Например `"player_death"`. Вызывается при конкретном событии.   | `game_event_t`     |
| `"unload"`        | Вызывается перед выгрузкой скрипта (для сохранения конфигов).   | \-                 |

Пример использования:

register_callback("paint", function()
    render.text("Hello CS2", 1, vec2_t(10, 10), color_t(255, 255, 255))
end)
