# Lua API Документация

Добро пожаловать в документацию Lua API! Данный ресурс предназначен для помощи в написании скриптов, предоставляя исчерпывающее описание всех доступных типов данных, глобальных функций и методов, экспортированных из C++ движка.

## Структура документации

В вашем распоряжении следующие разделы:

* **[Типы данных (Types)](types.md)** — Описание базовых и игровых типов, таких как вектора (`vec3_t`), углы (`angle_t`), цвета (`color_t`), а также игровые события (`game_event_t`) и параметры камеры (`view_setup_t`).
* **[Глобальные таблицы (Engine)](engine.md)** — Математические функции, конвертация углов и векторов, работа с переменными меню (`menu`).
* **[Сущности (Entity)](entity.md)** — Полное руководство по работе с игровыми сущностями (`base_entity_t`), чтение и запись сетевых переменных (netvars), а также получение информации об игроках.
* **[Рендер (Render)](render.md)** — Инструменты для загрузки шрифтов и работы с текстурами (включая динамические RGBA текстуры).

> **Примечание:** Документация сгенерирована строго на основе исходного кода `lua_engine`. Функции, не имеющие явных биндов в Lua (например, методы Blur, присутствующие в C++), не включены во избежание ошибок при написании скриптов.
