# Сущности (Entity)

API представляет все игровые объекты в виде типа `base_entity_t` (внутренняя метатаблица `Nixware_Entity`). Данный объект предоставляет безопасный динамический доступ к памяти игры и сетевым переменным (netvars).

## Базовые методы

Если вы обращаетесь к методу сущности, используйте строковый ключ или классический вызов:

* `entity:get_abs_origin() -> vec3_t`
  Возвращает абсолютные мировые координаты (origin) объекта. Обрабатывает чтение через `CGameSceneNode`.

* `entity:get_class_name() -> string`
  Возвращает имя класса сущности (например, `"C_CSPlayerPawn"`).

* `entity:get_entity_handle() -> number`
  Возвращает указатель (адрес) сущности в памяти игры в виде числа. Может использоваться для работы с библиотекой `ffi`.

## Динамический доступ к Netvars (Сетевым переменным)

API автоматически разрешает имена сетевых переменных, кэширует их смещения и конвертирует типы данных при доступе из Lua.

Вы можете читать и записывать значения напрямую по их имени в игре:

```lua
-- Чтение
local health = player.m_iHealth
local is_spotted = player.m_bIsSpotted
local origin = player.m_vecOrigin

-- Запись
player.m_iHealth = 100
player.m_bIsSpotted = true
```

### Приведение типов Netvars

Движок автоматически выбирает тип данных в зависимости от префикса или названия переменной:

| Префикс / Имя переменной | Тип в Lua | Примечание |
| :--- | :--- | :--- |
| `m_steamID` | `string` | Конвертируется из uint64 |
| `m_p...` | `base_entity_t` \| `nil` | Указатели на другие сущности |
| `m_Glow` | `base_entity_t` | Указатель на структуру Glow |
| `m_b...` | `boolean` | Логические флаги |
| `m_sz...`, `m_isz...`, `m_s...` | `string` | Строковые переменные |
| `m_fFlags`, `m_fEffects` | `number` | Флаги (целое число uint32) |
| `m_fl...`, `m_f...` | `number` | Числа с плавающей точкой (float) |
| `m_vec...`, `m_ang...`, `m_v...`| `vec3_t` | Векторы 3D |
| `m_h...`, `m_leader` | `base_entity_t` \| `nil` | Автоматически конвертирует Handle в сущность |
| Любые другие имена | `number` | По умолчанию читается как int32 |

## Доступ по смещению (Offset)

Если вам необходимо прочитать память по прямому смещению, передайте число в качестве индекса (вместо строки).
**Внимание:** В данный момент API возвращает адрес смещения как число `адрес_сущности + offset`.

```lua
local ptr = entity[0x100] -- Возвращает числовой адрес
```

## Сравнение сущностей

Сущности можно безопасно сравнивать оператором равенства `==`. Сравнение происходит по их фактическому указателю в памяти игры.

```lua
if entity1 == entity2 then
    -- Это один и тот же объект в игре
end
```
