# Рендер (Render)

Глобальная таблица `render` содержит функции для настройки и работы с графическими ресурсами: шрифтами и текстурами.

## Шрифты

* `render.setup_font(path: string, size: number, flags?: number) -> number`
  Инициализирует кастомный шрифт и возвращает его числовой ID (индекс).
  * `path`: Абсолютный или относительный путь к файлу шрифта (например, `C:\Windows\Fonts\tahoma.ttf`).
  * `size`: Размер шрифта.
  * `flags` (опционально): Флаги рендеринга шрифта.

## Текстуры и Изображения

* `render.setup_texture(path: string, flip_y?: boolean) -> number`
  Загружает текстуру с диска по указанному пути и возвращает её ID.
  * `path`: Путь к текстуре. (Строка приводится к нижнему регистру; пути, содержащие `avatarcache`, автоматически получают `flip_y = true`).
  * `flip_y` (опционально): Перевернуть текстуру по вертикали (по умолчанию `false`).

* `render.setup_texture_rgba(data: table, size: vec2_t) -> number`
  Создает новую динамическую текстуру из массива сырых пикселей и отправляет запрос на загрузку в GPU. Возвращает ID созданной текстуры, либо `-1` при ошибке.
  * `data`: Lua-таблица (индексированная от 1), содержащая числа `uint32_t`, представляющие цвета каждого пикселя в формате RGBA. Длина таблицы должна быть равна `width * height`.
  * `size`: Размеры текстуры (`vec2_t`), где `x` — ширина, `y` — высота.

* `render.update_texture_rgba(tex_id: number, data: table, size: vec2_t) -> boolean`
  Обновляет пиксели уже существующей динамической текстуры новыми данными.
  * `tex_id`: Индекс текстуры, ранее полученный через `setup_texture_rgba`.
  * `data`: Новая таблица с пикселями RGBA.
  * `size`: Размеры обновляемой текстуры.
