# 🧱 Данные и Структуры (Types)

API предоставляет набор математических примитивов, которые маппятся напрямую в C++ структуры движка. Они необходимы для работы с координатами, цветами и расчетами углов[cite: 14].

---

## `vec2_t`
Двумерный вектор. Чаще всего используется в API рендеринга для указания координат на экране (`X` и `Y`) и размеров текстур.

* **Поля структуры**: 
    * `x` (тип: `float`)[cite: 14]
    * `y` (тип: `float`)[cite: 14]

!!! tip "Пример создания"
    ```lua
    local pos = vec2_t(1920 / 2, 1080 / 2) -- Центр экрана
    ```

---

## `angle_t`
Структура Эйлеровых углов. Движок использует её для определения направления взгляда, расчета отдачи (recoil) и ориентации сущностей в трехмерном пространстве.

* **Поля структуры**:
    * `pitch` — Вертикальный угол (вверх/вниз)[cite: 14]
    * `yaw` — Горизонтальный угол (влево/вправо)[cite: 14]
    * `roll` — Наклон (поворот вокруг своей оси)[cite: 14]

---

## `color_t`
Базовая структура цвета с поддержкой альфа-канала. Используется во всех функциях отрисовки (`render.*`).

* **Поля структуры**:
    * `r` — Красный (Red), от 0 до 255[cite: 14]
    * `g` — Зеленый (Green), от 0 до 255[cite: 14]
    * `b` — Синий (Blue), от 0 до 255[cite: 14]
    * `a` — Альфа-канал / Прозрачность (Alpha), от 0 до 255[cite: 14]

!!! info "Особенности"
    Вы можете передавать цвета с разным уровнем прозрачности, что особенно полезно при создании UI с блюром или плавным `fade` переходом.

---

## 🖼 Внутренние типы (Изображения)

### `LuaImage`
Объект, представляющий загруженное изображение. Внутри движка хранит свой `id` в массиве кастомных текстур[cite: 14].
* **Методы**: 
    * `:get_size()` — возвращает `vec2_t` с реальными размерами изображения[cite: 14].
