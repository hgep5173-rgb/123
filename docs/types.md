# 🔢 Типы данных (Data Types)

Собственные математические типы данных движка (UserData). Написаны на чистом C++ для максимальной производительности при вызовах из Lua.

## `vec2_t`
Двухмерный вектор. Поддерживает математические операторы: `+`, `-`, `*`, `/`.

* **Создание:** `vec2_t(x, y)`
* **Поля:** `x`, `y`

## `vec3_t`
Трехмерный вектор. Поддерживает математические операторы: `+`, `-`, `*`, `/`.

* **Создание:** `vec3_t(x, y, z)`
* **Поля:** `x`, `y`, `z`
* **Методы:**
  * `vec:length()` — Полная длина вектора.
  * `vec:length_2d()` — Длина без учета оси Z.
  * `vec:length_sqr()` — Длина в квадрате (выполняется быстрее).
  * `vec:length_2d_sqr()` — Длина в 2D в квадрате.
  * `vec:dist_to(other_vec)` — Дистанция до другого вектора.
  * `vec:dist_to_2d(other_vec)` — Дистанция в 2D.
  * `vec:dot(other_vec)` — Скалярное произведение.
  * `vec:cross(other_vec)` — Векторное произведение (возвращает новый `vec3_t`).
  * `vec:normalized()` — Возвращает нормализованную копию вектора.
  * `vec:normalize()` — Нормализует вектор на месте и возвращает его старую длину.
  * `vec:lerp(other_vec, fraction)` — Линейная интерполяция (от 0.0 до 1.0).

## `vec4_t`
Четырехмерный вектор.

* **Создание:** `vec4_t(x, y, z, w)`
* **Поля:** `x`, `y`, `z`, `w`

## `color_t`
Цвет в формате RGBA. Значения задаются от `0` до `255`.

* **Создание:** `color_t(r, g, b, a)`
* **Поля:** `r`, `g`, `b`, `a`

## `angle_t`
Углы Эйлера (QAngle).

* **Создание:** `angle_t(pitch, yaw, roll)`
* **Поля:** `pitch`, `yaw`, `roll`
