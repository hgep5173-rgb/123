# Пользовательские типы (Types)

API предоставляет набор пользовательских типов данных (userdata) со своими метатаблицами для работы с математикой и структурами игры.

## Векторная математика

### `vec3_t`
Трехмерный вектор.
**Создание:** `vec3_t(x, y, z)`

**Поля:**
* `x` (number)
* `y` (number)
* `z` (number)

**Методы:**
* `length() -> number`: Возвращает длину вектора.
* `length_2d() -> number`: Возвращает 2D длину вектора (без учета координаты Z).
* `length_sqr() -> number`: Возвращает квадрат длины вектора.
* `length_2d_sqr() -> number`: Возвращает квадрат 2D длины.
* `dist_to(other: vec3_t) -> number`: Вычисляет дистанцию до другого вектора.
* `dist_to_2d(other: vec3_t) -> number`: Вычисляет 2D дистанцию до другого вектора.
* `dot(other: vec3_t) -> number`: Вычисляет скалярное произведение (dot product).
* `cross(other: vec3_t) -> vec3_t`: Возвращает векторное произведение (cross product).
* `normalized() -> vec3_t`: Возвращает новую нормализованную копию вектора (длина = 1).
* `normalize() -> number`: Нормализует текущий вектор на месте и возвращает его исходную длину.
* `lerp(other: vec3_t, fraction: number) -> vec3_t`: Выполняет линейную интерполяцию к другому вектору.

**Операторы:** Поддерживаются математические операторы `+`, `-`, `*`, `/` со скалярами и другими векторами.

### `vec2_t`
Двумерный вектор.
**Создание:** `vec2_t(x, y)`

**Поля:**
* `x` (number)
* `y` (number)

**Операторы:** Поддерживаются `+`, `-`, `*`, `/`.

### `vec4_t`
Четырехмерный вектор.
**Создание:** `vec4_t(x, y, z, w)`

**Поля:**
* `x` (number)
* `y` (number)
* `z` (number)
* `w` (number)

## Углы и цвета

### `angle_t`
Углы Эйлера для работы с вращениями.
**Создание:** `angle_t(pitch, yaw, roll)`

**Поля:**
* `pitch` (number)
* `yaw` (number)
* `roll` (number)

### `color_t`
Цвет в формате RGBA.
**Создание:** `color_t(r, g, b, a)`

**Поля:**
* `r` (number)
* `g` (number)
* `b` (number)
* `a` (number)

## Игровые структуры

### `convar_t`
Консольная переменная движка Source 2.
**Методы:**
* `get_name() -> string`: Получить имя ConVar.
* `get_desc() -> string`: Получить описание ConVar.
* `get_float() -> number`: Получить значение в виде числа с плавающей точкой.
* `get_int() -> number`: Получить значение в виде целого числа.
* `get_bool() -> boolean`: Получить значение в виде логического типа.
* `get_string() -> string`: Получить строковое значение.

### `game_event_t`
Объект внутриигрового события (Game Event).
**Методы:**
* `get_name() -> string`: Получить имя события (например, `"player_death"`).
* `get_int(key: string) -> number`: Получить целочисленный параметр по ключу.
* `get_float(key: string) -> number`: Получить float-параметр по ключу.
* `get_string(key: string) -> string`: Получить строковый параметр по ключу.
* `get_pawn(key: string) -> base_entity_t | nil`: Автоматически получить сущность пешки (player pawn) из слота игрока, переданного по ключу.
* `get_controller(key: string) -> base_entity_t | nil`: Автоматически получить контроллер игрока (player controller) из слота или хэша.

### `view_setup_t`
Параметры камеры игрока (используется в событии OverrideView).
**Поля:**
* `fov` (number): Текущий угол обзора.
* `fov_viewmodel` (number): Угол обзора моделей оружия рук (viewmodel).
* `origin` (vec3_t): Позиция камеры.
* `angles` (angle_t): Углы поворота камеры.

### `image_t`
Объект загруженного изображения (используется внутри движка рендера).
**Методы:**
* `get_size() -> vec2_t`: Возвращает размеры изображения (ширина, высота).
