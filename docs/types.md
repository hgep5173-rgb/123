# 🔢 Типы данных (Data Types)

Собственные математические типы данных движка (UserData). Написаны на чистом C++ для максимальной производительности.

---

## `vec2_t`
Двухмерный вектор. Поддерживает математические операторы: `+`, `-`, `*`, `/`.

* **Создание:** `vec2_t(x, y)`
* **Поля:** `x`, `y`

**Пример:**
```lua
local pos = vec2_t(100, 200)
local offset = vec2_t(50, 50)
local new_pos = pos + offset -- Результат: vec2_t(150, 250)
print("X:", new_pos.x, "Y:", new_pos.y)
```

## `vec3_t`
Трехмерный вектор. Поддерживает математические операторы: `+`, `-`, `*`, `/`.

* **Создание:** `vec3_t(x, y, z)`
* **Поля:** `x`, `y`, `z`
* **Методы:**
  * `vec:length()` — Возвращает полную длину вектора.
  * `vec:length_2d()` — Длина без учета оси Z.
  * `vec:length_sqr()` — Длина в квадрате (вычисляется быстрее).
  * `vec:length_2d_sqr()` — Длина в 2D в квадрате.
  * `vec:dist_to(other_vec)` — Дистанция до другого `vec3_t`.
  * `vec:dist_to_2d(other_vec)` — Дистанция в 2D пространстве.
  * `vec:dot(other_vec)` — Скалярное произведение.
  * `vec:cross(other_vec)` — Векторное произведение (возвращает новый `vec3_t`).
  * `vec:normalized()` — Возвращает нормализованную копию вектора (длина равна 1).
  * `vec:normalize()` — Нормализует текущий вектор на месте и возвращает старую длину.
  * `vec:lerp(other_vec, fraction)` — Линейная интерполяция между векторами.

**Пример:**
```lua
local p1 = vec3_t(0, 0, 0)
local p2 = vec3_t(100, 100, 50)
print("Distance:", p1:dist_to(p2))

local mid_point = p1:lerp(p2, 0.5) -- Получить точку ровно посередине
```

## `vec4_t`
Четырехмерный вектор.

* **Создание:** `vec4_t(x, y, z, w)`
* **Поля:** `x`, `y`, `z`, `w`

## `color_t`
Цвет в формате RGBA. Значения задаются от `0` до `255`.

* **Создание:** `color_t(r, g, b, a)`
* **Поля:** `r`, `g`, `b`, `a`

**Пример:**
```lua
local red = color_t(255, 0, 0, 255)
local semi_transparent_blue = color_t(0, 0, 255, 128)
```

## `angle_t`
Углы Эйлера (QAngle).

* **Создание:** `angle_t(pitch, yaw, roll)`
* **Поля:** `pitch`, `yaw`, `roll`
